# MeCab辞書エディタ

MeCab用ユーザー辞書ファイル（UTF-8形式のCSV）をブラウザ上で編集する Go アプリケーションです。
対象はリポジトリの [userdic/](../userdic/) です。
MeCab 本体のビルド・辞書コンパイル・読み専用辞書の説明は [ルートの README.md](../README.md)、エディタの開発・API・検証手順は [AGENTS.md](AGENTS.md) を参照してください。

## 機能

- `../userdic/` ディレクトリ内の辞書CSVファイルを一覧表示し、編集対象を選択
- 1ページ25件のページナビゲーション（大規模辞書にも対応）
- 一覧の「編集」ボタンからモーダルを開き、1エントリの全項目を編集
- 編集ボタンは左端、削除ボタンは右端に配置し、横スクロール時もそれぞれの端に固定
- 品詞・活用は `dicdef/parts-id.def` の定義から選択（キーワードや文脈IDで絞り込み可能）
- 「行追加」もモーダルで入力し、確定時に追加（キャンセルでは追加しない）
- モーダルの「適用」で一覧を更新し、「保存」でCSVへ書き込み
- 行の削除
- キーワードによるリアルタイム検索（サーバー側フィルタリング）
- UTF-8エンコーディングでCSVファイルに上書き保存
- 保存後は辞書選択画面に戻る

## ディレクトリ構成

```
.
├── main.go              # サーバー本体
├── dicdef/parts-id.def   # 品詞・活用と文脈IDの対応定義（UTF-8）
├── templates/
│   ├── index.html       # 辞書選択画面
│   └── edit.html        # 辞書編集画面
├── static/
│   ├── css/style.css    # スタイルシート
│   └── js/app.js        # フロントエンドJS
├── go.mod
├── kana_test.go         # 仮名変換・API更新の検証テスト
├── AGENTS.md            # 開発ガイド
└── Makefile
```

編集対象のCSVは、起動ディレクトリから見た `../userdic/` に置きます。
CSV はヘッダ行を付けずに用意してください。

## 辞書ファイルの形式

MeCab IPAdic互換のCSV形式（UTF-8）を対象としています。

| 列 | 内容 |
|----|------|
| 0 | 表層形 |
| 1 | 左文脈ID |
| 2 | 右文脈ID |
| 3 | コスト |
| 4 | 品詞 |
| 5 | 品詞細分類1 |
| 6 | 品詞細分類2 |
| 7 | 品詞細分類3 |
| 8 | 活用型 |
| 9 | 活用形 |
| 10 | 原形 |
| 11 | 読み |
| 12 | 発音 |

```text
みみの,1291,1291,8454,名詞,固有名詞,人名,名,*,*,みみの,ミミノ,ミミノ
```

13列を超える追加列がある場合、モーダルでは編集対象にしませんが、既存の値を保持して更新・保存します。

## 使い方

### ビルドと起動

リポジトリ直下から実行する場合は次を使います。

```bash
make dicedit
```

`dicedit/` へ移動して実行する場合は次のとおりです。

```bash
cd dicedit
make run
```

`dicedit/` 内で直接ビルド・起動することもできます。

```bash
go build -o dicedit .
./dicedit
```

ブラウザで `http://localhost:2080` にアクセスしてください。
サーバーの待受指定は `:2080` です。
CSV と静的ファイルのパスが相対指定なので、実行ファイルを直接起動するときも作業ディレクトリは `dicedit/` にしてください。

一覧は表示専用です。各行の左端の「編集」でモーダルを開き、「適用」で変更を確定します。
「キャンセル」または Esc キーで閉じた場合、入力内容は適用されません。
「行追加」はモーダルで入力し、「追加」を押した時点で登録します。キャンセル時に空行は追加されません。
右端の「削除」は確認後に行を削除します。
追加・編集・削除した内容をCSVファイルへ書き込むには、画面上部の「保存」を押してください。
モーダルでの通信に失敗した場合は入力内容を保持し、エラーを表示します。
送信中は入力・ボタン・Escによる閉鎖を無効にし、二重送信を防ぎます。

「適用」「追加」「削除」はサーバーのメモリ上のデータを変更します。CSVに書き込むには別途「保存」が必要です。
未保存の変更はサーバー終了時に失われます。
外部のエディタでCSVを変更しても、すでに読み込んだキャッシュは自動更新されません。

### 読み・発音の入力

「適用」「追加」の際、「読み」「発音」のひらがなは自動的にカタカナへ変換します。
カタカナ・長音記号（ー）・半角カナが使用でき、濁点・半濁点は仮名の直後で使用できます。
漢字・英数字・空白・句読点・`*` など、仮名以外の文字が含まれている場合は、エラーを表示して適用を止めます。
空欄はそのまま扱います。検証は画面とサーバーの両方で行い、不正なエントリを追加・更新しません。
エラー時は該当欄へフォーカスを移し、そのエントリ全体の適用を止めます。

| 入力例 | 適用される値 |
|---|---|
| `ひらがな` | `ヒラガナ` |
| `こーひー` | `コーヒー` |
| `カタカナ` | `カタカナ` |
| `ｺｰﾋｰ` | `ｺｰﾋｰ`（半角のまま） |

検証の対象は追加・更新するエントリです。CSVの読み込みや「保存」の際に、既存の全エントリを一括変換する機能ではありません。

### 品詞・活用の選択

モーダルの「品詞・活用」で、[dicdef/parts-id.def](dicdef/parts-id.def) の定義を選びます。現在の定義は1,316件です。
検索欄では、例えば「名詞 人名」や「1285」のように絞り込めます。絞り込みだけでは選択は変わりません。
絞り込み欄の Enter キーでは、確定せずに選択欄へフォーカスを移します。
定義を選択すると、品詞・品詞細分類1〜3・活用型・活用形と、左右の文脈IDが適用されます。
細分類・活用情報は選択した定義の表示専用です。原形・読み・発音・コストは変更せず保持します。

このリストは現在の IPADIC の左右の文脈ID定義と一致しているため、選択したIDを左右に設定します。
定義の最後の項目は接続に使う原形区分であり、CSVの原形をその値で上書きすることはありません。
既存エントリのID・品詞・活用が定義と一致しない場合は「現在の値を保持」と表示し、定義を選び直すまで元の値を保持します。
新規追加では、リストからの選択が必要です。

定義ファイルはビルド時に埋め込み、`GET /api/parts` で画面へ渡します。定義を更新した際は再ビルド・再起動してください。

### 保存後の辞書生成

このエディタはCSVを編集・保存するもので、バイナリ辞書を自動コンパイルする機能はありません。
保存後のコンパイル手順は [ルートの README.md](../README.md) を参照してください。

### コマンド

| コマンド | 内容 |
|----------|------|
| `make build` | バイナリをビルド |
| `make run` | ビルドして起動 |
| `make clean` | バイナリを削除 |
| `go test ./...` | 仮名変換・追加更新時の検証テストを実行 |

### コード・定義の更新

`templates/*.html` と `dicdef/parts-id.def` は `go:embed` でビルド時に埋め込みます。
これらやGoの実装を変更した場合は再ビルド・再起動してください。
JS/CSSは実行時に `static/` から配信するため、変更後はブラウザを再読み込みします。

## 動作要件

- Go 1.26.1 以降（`go.mod` に準拠）
